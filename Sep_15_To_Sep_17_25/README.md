# Telecom Customer Churn Prediction

This project predicts customer churn for a telecom company using various classification models and a CLI interface for predictions.

## Project Structure
- `Telecom_Customer_Churn_Prediction/data/` — Raw dataset (ignored in git)
- `Telecom_Customer_Churn_Prediction/models/` — Saved model files (.pkl)
- `Telecom_Customer_Churn_Prediction/notebooks/` — Jupyter notebooks for EDA and modeling
- `Telecom_Customer_Churn_Prediction/src/` — Source code (pipeline, preprocessing)


## Models Supported
- Logistic Regression
- Decision Tree
- KNN
- Random Forest
- XGBoost
- AdaBoost

## Requirements
- Python 3.8+
- pandas, scikit-learn, xgboost

## Notes
- The `data` folder is ignored.
- Model files are stored in `models/` and loaded for prediction.
- Notebooks provide detailed analysis and model training steps.
