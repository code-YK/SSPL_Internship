# Vehicle Price Prediction Task

This project predicts vehicle prices using machine learning models. It includes data preprocessing, exploratory data analysis, model training, evaluation, and user input prediction.

## Project Structure
- `data/` : Raw and processed datasets
- `models/` : Saved model files
- `notebooks/` : Jupyter notebooks for EDA and modeling
- `src/` : Source code modules

## Main Features
- Data cleaning and feature engineering
- Multiple regression models (Linear, KNN, Random Forest, XGBoost, Ridge, Lasso, SVR)
- Model evaluation and visualization
- User input prediction script

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run notebooks for EDA and modeling
3. Use `src/user_input_predict.py` for interactive predictions
